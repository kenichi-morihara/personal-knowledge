# 資金ロードマップ：画面案

[ゲーム風の画面案](index.html)と[落ち着いた画面案](calm.html)をブラウザで開けます。編集元は[ゲーム風](quest.fragment.html)・[落ち着いた案](calm.fragment.html)のHTML断片です。GitHubのファイル画面ではHTMLは表示されないので、ローカルファイルをブラウザで開くか、簡易HTTPサーバーで確認してください。

仮残高30万円以外の金額・日程はデモです。画面の試算はローカルに閉じており、金融記録・税金原本・既存の撮影/MCPサーバーには接続していません。デモ表示をオフにすると未確認として表示します。

計算は期限順に残高＋期間収入−期間支出−目標支払いを引き継ぎます。必要額として計上した支払いを期間支出へ二重計上しません。各期限の負の残高を不足額、全期間で最も大きい不足額を追加で必要な金額として表示します。

## ゲーム風の画面案

税金・移住費などをクエストの地点として並べ、資金が足りる見込みの地点と不足する地点を区別します。完了・支払済みとしては表示しません。大きな不足額、最初に不足する期限、目標資金の確保見込みを表示します。

各地点を開いて金額を調整し、「収入＋5万円で試算」で不足額の変化を試せます。仮残高30万円以外はすべてデモ。予定支出は目標支払いと重複しない生活費等として入力します。デモをオフにすると未確認表示になり、試算の編集は無効になります。

2026-10-25検証：ブラウザで追加収入5万円により全体不足81万円→76万円、最初の不足12万円→7万円になることを確認。デモオフ時の未算出表示とAndroid相当390px幅の表示も確認済みです。実データ接続やスマホへの公開はしていません。
