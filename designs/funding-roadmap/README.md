[ゲーム風の画面案](index.html)と[落ち着いた画面案](calm.html)をブラウザで開けます。編集元は[ゲーム風](quest.fragment.html)・[落ち着いた案](calm.fragment.html)のHTML断片です。GitHubのファイル画面ではHTMLは表示されないので、ローカルファイルをブラウザで開くか、簡易HTTPサーバーで確認してください。

仮残高30万円以外の金額・日程はデモです。デモの地点は「税金・保険料12万円（2026-11-30）」「年末の支払い20万円（2026-12-31）」「確定申告45万円（2027-03-15・期限は仮）」「モロッコ旅行52万円（2027-04頃・約2週間）」「スペイン旅行48万円（日程未定）」「東北車中泊22万円（レンタカー・日程未定）」「スラバヤ結婚式30万円（2027-07頃・約5泊）」「カナダ移住118万円（ビザ次第・渡航・保険・入居・帰国資金・予備費）」「カナダ 就職までの生活費（2027-09〜11・月48万円）」の9項目です。収入は本人年収800万円＋相手年収400万円の額面の約8割（二人計・月約80万円）を仮定し、生活費は家賃10万円（光熱費込み・2027年4月で引き払い）を含め4月まで月23万円、5月以降月13万円としています。画面の試算はローカルに閉じており、金融記録・税金原本・既存の撮影/MCPサーバーには接続していません。デモ表示をオフにすると未確認として表示します。

計算は期限順に残高＋期間収入−期間支出−目標支払いを引き継ぎます。必要額として計上した支払いを期間支出へ二重計上しません。各期限の負の残高を不足額、全期間で最も大きい不足額を追加で必要な金額として表示します。

## ゲーム風の画面案

税金・移住費などをクエストの地点として並べ、資金が足りる見込みの地点と不足する地点を区別します。完了・支払済みとしては表示しません。大きな不足額、最初に不足する期限、目標資金の確保見込みを表示します。金額は万円表示です。

各地点を開くと「月ごとの小イベント」（給与・生活費・家賃などの月次収支）が小さく並び、必要額（万円）を調整できます。「手元資金と毎月の収支を調整」から月収・生活費・家賃の月次仮定を変えられ、「収入＋5万円で試算」で変化を試せます。

記録は[db.json](db.json)が原本です（イベントごとに固定UUID・type・updated_at・出典を付けたJSON）。画面は起動時に db.json を読み、編集内容はブラウザ内（localStorage）に自動保存されます。「db.jsonをダウンロード」で現在の内容を書き出せるので、db.json に上書きすると次回以降の初期値になります。「初期値に戻す」は localStorage を消して既定値に戻します。金融記録・帳簿への書き込みは行いません。

2026-10-25検証：ブラウザで9地点デモ（手取り月約80万円想定）を確認。表示は万円（収入＋800万円・支出−334万円・必要額347万円）、9 / 9 地点で資金確保の見込い・最終残り149万円・不足0円。db.json の読み込み、必要額の編集による再計算と localStorage への保存、収入＋5万円の試算、デモオフ時の未算出表示を確認済みです。実データ接続やスマホへの公開はしていません。

落ち着いた画面案（calm）は同じ9地点を円表示の集計値で見られる旧来の簡易ビューです。月次小イベント・万円表示・DB連携はゲーム風のみの対応です。
